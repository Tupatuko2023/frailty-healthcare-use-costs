# AIM1 repository guidance

## Purpose and audience

This repository is the public research-code companion for the AIM1 study of
DEAC20 frailty, healthcare use and costs. It supports a manuscript targeting
*BMC Geriatrics*. Write for international researchers, peer reviewers and
readers who want to inspect or reuse the code.

## Language and evidence

- Write all maintained public documentation in clear academic English. This
  includes the README, running and testing instructions, methods descriptions,
  provenance summaries, limitations and release notes. Discussions with the
  owner may be in Finnish.
- Distinguish the implementation, synthetic test evidence, historical research
  runs in the protected source environment and reproduction runs performed from
  this repository. State which evidence supports each claim.
- Describe public code availability separately from scientific validation,
  end-to-end reproducibility, manuscript acceptance and research-data access.
  Verify any bibliographic, ethics or data-access statement before adding it.
- Preserve input names, technical identifiers, methods, model results, source
  references and licence notices. Keep closed task records as historical records.
  Label retrospective translations and identify the original revision.
- Use synthetic examples in public instructions. Keep research data, private
  configuration, identifiers and protected results outside this repository.
